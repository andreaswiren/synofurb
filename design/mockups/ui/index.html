synofurb UI: three visual directions

The same screen in each direction: the Confirm gate of the desktop installer for a sample DS918+ (all data on these pages is sample data). Only Direction 1 was revised after the independent UI critic review (it now matches the revised UX concept); Directions 2 and 3 are kept as alternatives and still show the first-round layout and copy.

Direction 1: ForgeVault family Recommended base, revised

Calm, neutral, dependable. Revised after the UI critic review: top stepper, safety rail, pinned action bar; red only on the erase button and the "Will be destroyed" marker; 960 x 640 to 1440 x 900; web plane reflows to 390 px; states sheet. Contrast: 472 of 472 checked pairs pass (lowest text 4.78:1), tools/contrast.py.
