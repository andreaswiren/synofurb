Getting DSM back after the point of no return

The NAS boots Synology’s loader, which shows an install page. Open find.synology.com (or Synology Assistant), find the unit and install DSM again with the .pat file for your model from Synology. Synology documents a reinstall that can keep data volumes: check its current documentation for your model and DSM version. This project cannot guarantee it. After a Wipe install there is no data left to keep. DSM settings, packages and users are lost either way.

How you get back

Power-cycling the NAS always returns to the default entry. The boot agent returns to DSM by itself after 30 minutes without a login. Once you start another system with kexec from the agent, nothing of ours is running: only a power cycle brings you back. We cannot promise an automatic return from a system we did not install.
