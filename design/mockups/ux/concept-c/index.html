Compatibility: DS918+

✓ VerifiedList v2026.10.3 · entry updated 2 Sep 2026 · 3 maintainer reports

Installs have been completed on real DS918+ hardware with Debian 13 and the 6.12 LTS kernel. Your unit matches the tested configuration (4 bays, BIOS boot, kexec available).

Known to work

  • kexec boot into installer
  • All 4 SATA bays, hot-swap
  • Both GbE ports
  • Serial console ttyS0
  • RAID 5 / 6 / 10, xfs

Known issues

  • Front status LED stays amber
  • Fan speed fixed by BIOS (no OS control)

Untested

  • Kernel 7.x (1 community report)
  • DX517 expansion unit
  • Wake-on-LAN
  • Buzzer

“Verified” means reproduced by maintainers on this model. It still does not guarantee your disks or your data survive. View entry in the repository

If something goes wrong

  1. Before the point of no return (installer steps 1–3): press Cancel, or just reboot the NAS. DSM starts again exactly as it is now. Disks have not been written.
  2. After it: DSM is gone. We keep a copy of each disk’s first 1 MiB (partition tables, RAID headers) on this computer and a rescue SSH shell stays open, so a failed step can be retried or inspected.
  3. Back to DSM means reinstalling it with Synology’s own tool (find.synology.com), then restoring from your backup. We will walk you through it.

2Plan: boot manager✓ valid

What gets installed

  • A small boot menu (GRUB, 6 MiB) and a netboot agent (about 40 MiB) on the NAS boot flash, not on your disks.
  • An SSH server in the boot environment (key only) so you can drive it from this computer or from ssh boot@192.168.1.40.
  • A fallback timer: if an OS you tried does not report back in 15 minutes the NAS reboots into the default entry (DSM).

What it does not do

  • Does not write to disks or touch DSM volumes.
  • Does not make other OSes safe: an OS you netboot can still format disks you let it see. We tell you which disks it will see.
▲

3Getting DSM back

Getting original DSM back

Synology has its own, supported reinstall path. We cannot replace it, but we can tell you when it will work:

  1. Put the NAS in DSM install mode: hold the RESET button until it beeps, release, press and hold again until the second beep (model specific; see Synology’s page for DS918+).
  2. On a computer on the same network open find.synology.com (or Synology Assistant). The NAS shows as “Not installed”. Choose Install.
  3. If the original DSM data volumes were never touched (Keep mode, install not yet past step 4) Synology’s installer offers to keep your data. After a wipe, the data is gone; restore from backup.
