Pick an action. Install and Boot manager open a focused flow you can exit at any time.

Install Debian

Replaces DSM · erases disks

Turn this NAS into a plain Debian 13 server on LVM + xfs with mdadm RAID.

  • About 25 minutes
  • You choose: wipe everything, or keep existing volumes (best effort)
  • Needs your backup

Boot manager

Disks untouched · reversible

Add a small boot menu you control over SSH, then netboot any OS to try it. DSM keeps working.

  • About 5 minutes
  • Lives on the NAS boot flash, not on your disks
  • Always one command from DSM

Restore / Recover

For failed or converted units

Return to original DSM, remove the boot manager, or open a rescue shell on a unit that will not boot.

  • Walks you through Synology’s own reinstall path
  • Uses the disk-header backup if one exists

Boot manager on DS918+🔒 Nothing written yet

Set up the boot manager

A small, SSH-controlled boot menu. Try any OS, always get back to DSM.

What gets installed

  • A small boot menu (GRUB, 6 MiB) and a netboot agent (about 40 MiB) on the NAS boot flash, not on your disks.
  • An SSH server in the boot environment (key only) so you can drive it from this computer or from ssh boot@192.168.1.40.
  • A fallback timer: if an OS you tried does not report back in 15 minutes the NAS reboots into the default entry (DSM).

What it does not do

  • Does not write to disks or touch DSM volumes.
  • Does not make other OSes safe: an OS you netboot can still format disks you let it see. We tell you which disks it will see.
▲
Flash space is limitedThe boot flash has 118 MiB free on this unit, enough for the manager. Without it we would need a 1 GiB partition on a disk, which does modify the partition table. Choose that instead
